# LiF SEI Topology Transport Analysis

This repository contains analysis and plotting utilities used for the study:

**Crystallization-Driven Octahedral Network Formation and Its Suppression Enable Tunable Li+ Transport in LiF-Rich SEIs**

The scripts analyze NEP/GPUMD molecular dynamics outputs for LiF-rich inorganic solid electrolyte interphase models. They generate the main quantities discussed in the manuscript, including NEP training parity plots, thermodynamic time series, Li mean-squared displacement, local Li coordination motif populations, motif residence times, and tetrahedral-octahedral interconversion frequencies.

## Installation

Create a clean Python environment and install the dependencies:

```bash
conda create -n lif-sei-topology python=3.10 -y
conda activate lif-sei-topology
pip install -r requirements.txt
```

The structure-selection workflow additionally requires ASE and scikit-learn, both of which are listed in `requirements.txt`.

## Input files expected by each script

| Script | Purpose | Required input files in the working directory |
|---|---|---|
| `analyze_coordination_motif_dynamics.py` | Classifies Li local environments as tetrahedral, octahedral, or other; computes motif survival probabilities, motif populations, and T-to-O/O-to-T conversion frequencies. | `positions.xyz` |
| `plot_li_msd.py` | Plots Li MSD and self-diffusion coefficient curves from GPUMD output and fits the Li diffusion coefficient. | `msd.out` |
| `plot_thermodynamic_evolution.py` | Plots temperature, kinetic energy, potential energy, density, and stress/pressure tensor components from GPUMD output. | `thermo.out`, `model.xyz` |
| `plot_nep_training_validation.py` | Generates NEP loss and parity plots for energies, forces, virials, and stresses. | Standard NEP training output files produced by GPUMD/NEP |
| `select_representative_structures.py` | Selects representative structures from an XYZ trajectory using descriptor reduction and sampling. | `dump.xyz`; optional descriptor files |

## Typical usage

### 1. Thermodynamic time series

Run this command in a GPUMD simulation folder containing `thermo.out` and `model.xyz`:

```bash
python scripts/plot_thermodynamic_evolution.py
```

The script writes `Figure2e.png`.

### 2. Li MSD and diffusion coefficient

Run this command in a folder containing `msd.out`:

```bash
python scripts/plot_li_msd.py 500 500
```

The two numerical arguments define the time excluded from the beginning and end of the MSD linear fit, in ps. The script writes `msd_Li.png`, `msd_Li.pdf`, `sdc_Li.png`, `sdc_Li.pdf`, and `diffusion_fit_summary_Li.txt`.

### 3. Coordination motif residence and interconversion analysis

Run this command in a folder containing `positions.xyz`:

```bash
python scripts/analyze_coordination_motif_dynamics.py
```

The script uses the following default motif definitions:

- Tetrahedral Li: four F neighbors within 2.8 Å and F-Li-F angles within 109.5° ± 25°.
- Octahedral Li: six F neighbors within 2.8 Å and F-Li-F angles within ±30° of 90° or 180°.

The script writes:

- `motif_conversion_frequency.png`
- `motif_survival_probability.png`
- `motif_survival_probability_0_10ps.png`
- `motif_population_timeseries.png`

### 4. NEP training and validation plots

Place the NEP training outputs in the working directory and run:

```bash
python scripts/plot_nep_training_validation.py
```

The script generates loss and parity plots for the NEP model.

### 5. Representative structure selection

Place `dump.xyz` in the working directory and run:

```bash
python scripts/select_representative_structures.py select pca 100
```

This command selects representative configurations based on the available descriptor workflow.

## Model and example files

The `models/nep.txt` file is the NEP potential included in the uploaded code package. The `examples/` directory contains representative GPUMD input files and a small model structure. Large trajectory files such as `positions.xyz`, `thermo.out`, `msd.out`, and full training outputs are not included because they are normally generated by GPUMD simulations and can be large.
